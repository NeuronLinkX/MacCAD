# MacCAD

맥에서 쓰는 AutoCAD 방식의 2D·3D CAD입니다. 명령 입력, 단축키, 객체 스냅, 치수, 도면층, 배치는 AutoCAD 2006과 같은 방식으로 움직이고, 그 위에 3D 솔리드·곡면 모델링과 내 컴퓨터 안에서 도는 AI 도우미를 얹었습니다. Electron 앱이고 애플 실리콘(arm64) 맥을 대상으로 합니다.

이 저장소에는 앱 소스(`src/`)만 들어 있습니다. 설치 파일(DMG)과 빌드 도구, 시험, 문서는 올려 두지 않았습니다.

## 할 수 있는 일

- 2D 제도: 선, 폴리선, 원, 호, 타원, 스플라인, 해치, 문자, 표, 블록, 치수, 도면층, 배치(레이아웃)
- 파일: DWG, DXF, STEP, STL, PDF를 열고, 자체 형식 `.mcad`로 저장합니다. DWG는 편집 가능한 상태로 열립니다.
- 3D: 솔리드 만들기, 불리언, 모깎기·모따기, 곡선에서 곡면 만들기, 곡면으로 자르기·붙이기, 메시 다루기, 사용자 좌표계(UCS), 보기 스타일
- Studio: 장면, 재질, 바닥 반사로 모델을 보기 좋게 보여 주는 렌더링 화면
- AutoLISP: 인터프리터가 들어 있고 명령줄, `.lsp` 파일, DCL 대화상자, Visual LISP 편집기를 씁니다.
- AI 도우미: 이 맥에서 도는 언어 모델(Ollama, LM Studio 등)과만 이야기합니다. 도면이 인터넷으로 나가지 않습니다.
- 명령은 모두 334개입니다(2D 233개, 3D 101개).

## 에디션

같은 소스에서 두 앱을 만듭니다. 어느 쪽인지는 환경 변수 `MACCAD_EDITION`(`2d` 또는 `3d`, 기본 `3d`)이 정합니다.

| | 2D | 3D (2D + 3D) |
|---|---|---|
| 제품 이름 | MacCAD 2027 2D | MacCAD 2027 3D |
| 3D 기능 | 없음 | 있음 |

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `src/main/` | 메인 프로세스: 창, 파일 입출력, DWG 읽기·쓰기, AI 중계, 라이선스, 보안 규칙 |
| `src/renderer/js/` | 화면과 CAD 본체: 명령, 도면 자료구조, 3D 커널 연결, AutoLISP, 대화상자 |
| `src/renderer/` | 화면 파일, 글꼴, 스타일, 시작 화면 그림 |
